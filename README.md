# Local LLM Chat (Windows Local Mode)

Desktop-focused chat app for LM Studio with no cloud auth and no cloud database.

## What changed

- No Google sign-in required
- No Supabase required for normal use
- Single local user mode (`local-machine-user`)
- Data stored on Windows machine in `C:\ProgramData\local-llm-chat`
- Chat data stored as JSON files per chat
- Attachments stored on local disk

## Data layout

When run via Electron desktop app, data is written under:

```text
C:\ProgramData\local-llm-chat\
  chats\local-machine-user\chats.json
  messages\<chatId>\messages.json
  users\local-machine-user\settings.json
  attachments\...
```

## Requirements

- Node.js 18+
- LM Studio running on your network (example: `http://192.168.1.10:1234`)
- Windows machine for MSI packaging

## Development setup

```bash
npm install
npm run build
npm run dev
```

Open:

```text
http://localhost:3000
```

## Desktop app (Electron)

Run desktop in dev mode:

```bash
npm run desktop:dev
```

## Build MSI on Windows

Run this on a Windows machine:

```bash
npm install
npm run desktop:pack:win
```

The MSI output will be generated by `electron-builder` in the `dist` folder.

## Notes

- This project still includes Supabase/NextAuth code paths as fallback compatibility, but local desktop mode does not require them.
- For packaged desktop app, Electron starts a local Next.js server internally.
- If your LM Studio runs on another machine, set the full network URL in Settings.
